# FortressArch

FortressArch is an Arch Linux based project focused on self-healing and
proactive protection, with a friendly installation and configuration
experience.

## Modules

1. Snapshot and auto-rollback on boot failure
2. Health monitoring daemon
3. Proactive sandboxing
4. Notifications and UI

## Status

Early development. See `docs/ROADMAP.md` for the full plan and current
progress.
